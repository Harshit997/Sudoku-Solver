# 🧩 Sudoku Solver in Java

A Sudoku Solver built in **Java** using recursion and backtracking.

## 🧠 About the Project
This program solves any valid 9x9 Sudoku puzzle by filling empty cells (denoted by 0).  
It uses recursion and backtracking to explore possible number placements efficiently.

## ⚙️ How It Works
- Validates each digit in row, column, and 3x3 subgrid.
- Uses a recursive function to fill empty cells.
- Backtracks when a placement violates Sudoku rules.
